# Личный Веб-Дневник (Django & Bootstrap)
http://81.177.49.243
Современное адаптивное веб-приложение для ведения личных заметок и дневниковых записей. Приложение полностью изолировано для каждого пользователя: каждый видит, создает, редактирует и удаляет исключительно свои собственные записи.

## Функционал приложения

1. Аутентификация и безопасность:
   - Регистрация новых пользователей.
   - Авторизация (вход) и завершение сессии (выход).
   - Ограничение доступа к страницам (анонимные пользователи не могут просматривать чужие дневники или создавать записи).
2. Управление записями (CRUD):
   - Создание новой записи (Заголовок, Текст).
   - Чтение (Просмотр списка всех своих записей и детальной страницы конкретной заметки).
   - Редактирование существующих записей.
   - Удаление записей с модальным или страничным подтверждением.
3. Поиск:
   - Полнотекстовый поиск по заголовку и содержимому записей на главной странице.
4. Адаптивный дизайн:
   - Интерфейс разработан с использованием Bootstrap 5, отлично отображается на смартфонах, планшетах и десктопах.
5. Панель администратора:
   - Полная интеграция с Django Admin для управления пользователями и модерации записей.

---

## Стек технологий

- Backend: Python 3.11+ / Django 5+
- Frontend: HTML5, CSS3, Bootstrap 5 (через CDN)
- База данных: PostgreSQL 16
- Контейнеризация: Docker / Docker Compose

## Инструкция по установке и запуску (Через Docker)

### 1. Подготовка окружения
Убедитесь, что на вашем компьютере установлены Docker и Docker Compose.

Клонируйте репозиторий с проектом или перейдите в его корневую директорию:
```bash
cd diary_project
```

### 2. Настройка переменных окружения
Создайте файл .env в корневом каталоге проекта и укажите настройки для базы данных PostgreSQL и Django. Пример содержимого .env:

```env
DEBUG=True
SECRET_KEY=django-insecure-your-super-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1

# Настройки PostgreSQL
DB_NAME=diary_db
DB_USER=diary_user
DB_PASSWORD=diary_secure_pass
DB_HOST=db
DB_PORT=5432
```

### 3. Сборка и запуск контейнеров
Запустите сборку образов и поднятие контейнеров в фоновом режиме:
```bash
docker-compose up --build -d
```

### 4. Выполнение миграций базы данных
Создайте необходимую структуру таблиц в вашей базе данных PostgreSQL внутри запущенного контейнера:
```bash
docker-compose exec web python manage.py migrate
```

### 5. Создание суперпользователя (Администратора)
Чтобы иметь доступ к встроенной панели администратора Django, создайте аккаунт администратора:
```bash
docker-compose exec web python manage.py createsuperuser
```
Следуйте инструкциям в терминале (введите имя пользователя, email и пароль).

## Использование приложения

После успешного выполнения всех шагов приложение станет доступно по следующим адресам:

- Главный сайт: http://localhost:8000/ — здесь вы можете зарегистрироваться, войти в систему и начать вести свой дневник.
- Панель администратора: http://localhost:8000/admin/ — используйте данные созданного суперпользователя для управления всеми записями и учетными записями в системе.

### Полезные команды Docker:
- Остановка проекта: docker-compose down
- Просмотр логов веб-приложения: docker-compose logs web
- Перезапуск контейнеров: docker-compose restart
